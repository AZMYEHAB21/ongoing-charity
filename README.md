موقع **صدقة جارية** هو موقع إسلامي بسيط يهدف إلى نشر الخير، ويحتوي على:
- القرآن الكريم (عرض وتشغيل السور)
- أذكار الصباح والمساء
- مسبحة إلكترونية
- أدعية للمتوفى
